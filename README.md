# MenubarDock: macOS-Style Top Menu Bar for Windows 11

**MenubarDock** is a lightweight, high-performance Windows 11 desktop utility that adds an elegant, translucent **macOS-inspired top Menu Bar** to your desktop.

---

## Features

- **Apple System Menu ()**: Quick access to About This PC, System Settings, Task Manager, Sleep, Restart, Shutdown, and Lock Screen.
- **Active Application Indicator**: Real-time dynamic name of currently focused application (e.g. "Finder", "Visual Studio Code", "Google Chrome").
- **Live System Status Widgets**:
  - 🔋 **Live Battery Indicator**: Battery percentage + dynamic charging indicator.
  - 📶 **Live Wi-Fi / Network Indicator**: Connection status icon.
  - 🔍 **Spotlight Search**: 1-click trigger for Windows Search (`Win + S`).
  - 🎛️ **Control Center**: 1-click trigger for Windows Quick Settings (`Win + A`).
  - 🕒 **Live Date & Clock**: Formatted date and time (`Win + N` notification trigger on click).
- **Instant Toggling**:
  - Global Hotkey: **`Ctrl + Alt + M`** to show/hide at any time.
  - System Tray menu icon with settings and toggle controls.
- **High-DPI & Multi-Monitor**:
  - Full Per-Monitor V2 DPI awareness (100% to 200%+ scaling).

---

## Keyboard Shortcuts

| Shortcut | Action |
| --- | --- |
| `Ctrl + Alt + M` | Toggle show / hide Menu Bar |
| `Win + A` | Quick Settings (Wi-Fi, Bluetooth, Volume) |
| `Win + N` | Notification Center & Calendar |
| `Win + S` | Windows Search / Spotlight |

---

## Installation

1. Download `MenubarDock-v1.0.0-win-x64.zip` from Releases.
2. Extract the ZIP file.
3. Right-click `Install-MenubarDock.ps1` → **Run with PowerShell** (or run `MenubarDock.exe` directly).
